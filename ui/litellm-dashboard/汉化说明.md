# LiteLLM UI 汉化分支（v1.109.1）

这个分支基于 LiteLLM `v1.109.1` 的 `ui/litellm-dashboard`，用于食汇网关的
中文界面。**不是官方 i18n**：官方 `en.json` 只覆盖 workflows / policies /
guardrails，所以这里用源码级替换。

## 当前覆盖

- 登录页、左侧导航、首页概览、虚拟密钥、模型与端点、日志、用量等主壳文案；
- 通过 `translate.mjs` + `zh-dict.json` 批量替换 JSX 文本 / 显示属性 /
  对象里的 label/title/description/groupLabel；不碰 href、路由、状态枚举；
- 构建：`npm ci && npm run build`（Node 24+）。

## 词典 / 继续汉化

- `zh-dict.json`：英文 → 中文；只放**显示文案**，不要放 status/role 等逻辑值；
- `translate.mjs`：按词表扫描 `src/`（跳过测试）；可重复运行，已翻译的中文不会重复处理；
- 新增词条后重跑 `node translate.mjs`，再 build。

## 已知边界

- 动态拼接句、新闻/博客内容、模型名/Key 保持英文；
- 深层页面仍有未覆盖的英文，按页面继续补词条；
- 本分支是 v1.109.1 的 UI 源码，升级 LiteLLM 时需重新 rebase 并补新文案。
